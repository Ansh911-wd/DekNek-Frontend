# DekNek Task Manager 🚀

A full-stack task manager app built using MERN stack.

## 🔗 Live Demo
Frontend: https://dek-nek-frontend-omega.vercel.app/
Backend: https://task-manager-backend-3sne.onrender.com/

---

## Features
- User Signup & Login (JWT Auth)
- Protected Routes
- Add Task
- Edit Task
- Delete Task
- Clean UI Dashboard

---

## Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB
- Auth: JWT

---

## Setup

### Backend
cd server  
npm install  
npm start  

### Frontend
cd client  
npm install  
npm start  

---

## API Endpoints

### Auth
POST /api/auth/signup  
POST /api/auth/login  

### Tasks
GET /api/tasks  
POST /api/tasks  
PUT /api/tasks/:id  
DELETE /api/tasks/:id
